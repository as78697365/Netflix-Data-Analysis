# Netflix Data Analysis

Author: Abhishek Sharma

## Problem Statement

Analyze Netflix dataset to understand content distribution, popular genres, and country-wise content production.

## Tools Used

* Python
* Pandas
* Matplotlib
* Seaborn
* Power BI

## Project Files

* netflix-data-analysis.ipynb → Data cleaning and analysis
* NETFLIX_DASHBOARD_POWER_BI.pbix → Power BI dashboard

## Key Insights

* Movies dominate Netflix content.
* USA produces the highest number of titles.
* Netflix content increased rapidly after 2016.
